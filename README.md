# Netpractice

*This project has been completed as part of the 42 curriculum by jegerman.*

## Description

Netpractice is the very first network-focused project of the 42 curriculum.

Its goal is to learn networking basics such as IP addresses, routing and
subnetting, and the role of network components such as clients, routers,
switches and the Internet, via 10 gradually difficult exercices involving
diverse network configurations.

Those exercices typically presents a dysfunctional network that the student
will have to troubleshoot and solve by adding the right IPs, subnet masks,
IP routes... for the network to work properly.

## Instructions

A website is provided by 42 and can be found in the school's intranet or
this repository in the dev-jeff branch.

Open `index.html` to be presented with two options:
* **Training** allows the student to hone their skills by going through the 10
levels of netpractice. After each level completion, the student should export
their configuration via a dedicated button in order to prepare the defense.
* **Evaluation** is a time-bound exercice where the student will have to
complete 3 randomly selected level between 6 and 10 be graded by an evaluator.
